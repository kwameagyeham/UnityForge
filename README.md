UnityForge utilizes Real-Time Processing and Multi-Threading to optimize Auto-Scaling in modular System components.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/UnityForge.git`
2. `cd UnityForge`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure UnityForge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
